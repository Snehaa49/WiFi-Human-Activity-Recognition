# WiFi-Sense: Human Activity Recognition from WiFi CSI

A deep-learning mini project that classifies human activities from WiFi Channel State Information (CSI). The notebook builds and compares six neural-network architectures in PyTorch using the UT-HAR dataset.

## Overview

WiFi signals change as people move through an environment. This project uses those signal variations to recognize seven activities:

- Lie down
- Fall
- Walk
- Pick up
- Run
- Sit down
- Stand up

The project implements the models directly in PyTorch rather than relying on pretrained model code.

## Models Compared

| Model | Approach |
|---|---|
| MLP | Fully connected baseline using flattened CSI input |
| CNN | Convolutional model that learns local signal patterns |
| LSTM | Recurrent model for sequential CSI readings |
| BiLSTM | Bidirectional LSTM that processes the sequence in both directions |
| GRU | Gated recurrent unit model |
| MiniResNet | Convolutional network with residual/skip connections |

The notebook trains and evaluates the models, then compares test accuracy, parameter count, and training time. It also generates an accuracy chart, a confusion matrix, and a sample CSI visualization.

## Dataset

The notebook downloads the UT-HAR dataset from the public Kaggle mirror:

`hylanj/wifi-csi-dataset-ut-har`

The dataset is downloaded at runtime using `kagglehub`; the dataset files are not included in this repository. An internet connection is required. Dataset source is acknowledged in the notebook as Yousefi et al. (2017).

## Run the Notebook

### Recommended: Google Colab

1. Open `notebooks/WiFi_HAR_From_Scratch.ipynb` in Google Colab.
2. Select **Runtime → Change runtime type**.
3. Choose a GPU runtime (the notebook recommends a T4 GPU).
4. Run the cells from top to bottom.
5. Allow the notebook to download the dataset and train the models.

A GPU is recommended because the notebook trains six neural networks. Training all models may take a while; you can run individual model-training cells separately if needed.

### Local environment

1. Create and activate a Python virtual environment.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start Jupyter:

   ```bash
   jupyter notebook
   ```

4. Open the notebook and run the cells in order.

The notebook automatically selects CUDA when available; otherwise, it uses CPU. CPU training may be substantially slower.

## Generated Outputs

After running the notebook, it creates files such as:

- `csi_samples.png` — example CSI visualizations
- `model_comparison.csv` — model metrics
- `accuracy_chart.png` — model accuracy comparison
- `confusion_matrix.png` — confusion matrix for the best-performing model
- `*_uthar.pt` — trained PyTorch model weights
- `stream.npz` — a small sample stream created near the end of the notebook

These are generated during execution and are not required to upload the notebook itself. Large model-weight files are excluded by `.gitignore` by default.
